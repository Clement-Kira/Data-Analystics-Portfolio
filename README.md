# 🚲 Bike Sales Analysis Dashboard

## 📊 Project Overview

This project focuses on cleaning, transforming, and analysing bike sales and customer data using Microsoft Excel.

The goal was to take a raw dataset, clean and prepare the data for analysis, and then build an interactive dashboard that provides insights into customer demographics, income, purchasing behaviour, and other factors that may influence bike purchases.

This project was completed as part of my ongoing development in **Data Analytics**, with a focus on practical Excel skills, data cleaning, data analysis, PivotTables, PivotCharts, and dashboard development.

---

## 🎯 Objectives

The main objectives of this project were to:

- Clean and prepare raw customer and sales data for analysis
- Identify and handle inconsistencies in the dataset
- Organise data into a format suitable for analysis
- Create PivotTables to summarise the data
- Build interactive charts and visualisations
- Develop an Excel dashboard for exploring customer behaviour
- Identify patterns between customer demographics and bike purchases
- Present data in a clear and understandable format

## 🧹 Data Cleaning

The original dataset required cleaning and preparation before analysis.

The cleaning process included:

- Reviewing the dataset for inconsistencies
- Checking data types and formatting
- Organising columns and records
- Removing or addressing incorrect/inconsistent data
- Preparing categorical fields for analysis
- Ensuring numerical fields were suitable for calculations
- Structuring the dataset for PivotTable analysis

The cleaned dataset was then used as the foundation for the dashboard.

---

## 📈 Dashboard

The Excel dashboard provides an interactive view of customer and bike purchasing behaviour.

### Dashboard Features

The dashboard includes interactive filters/slicers for:

- **Marital Status**
- **Region**
- **Occupation**
- **Purchased Bike**
- **Age Brackets**

### Visualisations

The dashboard includes visualisations such as:

- Average Income per Purchase
- Customer Commute Analysis
- Bike Purchase comparisons
- Gender-based purchasing analysis
- Customer demographic analysis

The slicers allow users to filter the dashboard and explore different customer segments.

---

## 🔍 Key Areas of Analysis

The project explores relationships between:

- Customer gender and bike purchases
- Income and bike purchasing behaviour
- Age groups and purchasing behaviour
- Occupation and bike purchases
- Region and purchasing behaviour
- Marital status and purchasing behaviour
- Customer commute patterns

These analyses help demonstrate how customer characteristics can be used to understand purchasing behaviour.
